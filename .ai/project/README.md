# Project Docs

本目录保存项目结构和运行时导航。

## 阅读顺序

按任务选择阅读，不默认全量读取本目录：

- 项目定位与技术栈：`overview.md`
- 总体架构和组件关系：`architecture.md`
- 分层边界：`layers.md`
- 协议接口运行链路：`runtime-chain.md`
- 编码风格、注释和 Pydantic 使用边界：`code-style.md`
- FastAPI、Taskiq、数据库和异常处理：`runtime.md`
- 表模型、协议模型和迁移：`data-models.md`
- 领域模块状态矩阵：`domain-status.md`
- 指标和观测：`observability.md`
- Docker、Helm、worker 和探针：`deployment.md`
