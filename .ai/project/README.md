# Project Docs

本目录保存项目结构和运行时导航。

## 阅读顺序

1. `overview.md`：系统定位与技术栈。
2. `architecture.md`：总体架构和请求链路。
3. `layers.md`：分层边界。
4. `runtime-chain.md`：协议接口运行链路图。
5. `code-style.md`：协议优先、命名、查询语义和 TDD 规则。
6. `runtime.md`：FastAPI、Taskiq、数据库和异常处理。
7. `data-models.md`：表模型、协议模型和迁移。
8. `domain-status.md`：领域模块状态矩阵。
9. `observability.md`：指标和观测。
10. `deployment.md`：Docker、Helm、worker 和探针。
